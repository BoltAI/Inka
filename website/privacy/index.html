Inka Privacy Policy

Effective date: July 10, 2026

Inka is an AI daily journal app for BOOX e-ink tablets.

The Inka app does not use accounts, ads, analytics, telemetry, crash reporting, or an Inka-owned backend.

Website analytics

This website uses Simple Analytics to understand aggregate visitor traffic. Simple Analytics does not use cookies, collect personal data, or create visitor profiles. Each page view is measured independently and is not used to track you across visits or websites.

Data stored on your device

Inka stores notebook data locally in app-private storage on your Android device. API keys are stored locally using encrypted Android preferences when available.

AI providers

Inka supports user-provided API keys for OpenAI, Anthropic, and Groq. When you ask Inka for an AI reply, Inka sends the recognized text from your handwriting directly to the AI provider you selected. That request is made from your device using your API key. The provider processes the request under its own terms and privacy policy.

Inka does not receive or store your AI requests on a developer-operated server.

Handwriting recognition

Inka uses on-device handwriting recognition after a one-time model download. Your handwriting recognition runs on the device.

Phone API key setup

To make API key setup easier on e-ink tablets, Inka can show a QR code and temporarily start a local setup page on the tablet. The setup page is available only while the setup dialog is open. If you submit an API key from your phone, the key is sent directly from your phone to your tablet over your local network, then stored on the tablet.

Experimental handwriting synthesis

Inka includes an optional developer setting for handwriting synthesis through a server endpoint you configure. If you enable this feature, generated reply text may be sent to that endpoint. Do not enable this feature with a server you do not trust.

Data deletion

You can delete local notebook data in the app or remove all local data by uninstalling Inka from your device. Inka does not have a developer-hosted account or server-side user database.
